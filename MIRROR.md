# This repository is a mirror

The source of this SDK is `sdk/typescript` in Shield360, which is a private
repository. This one is rebuilt from it and force-pushed, so a commit made here
directly is lost on the next sync and pull requests cannot be merged.

**Issues are welcome here** — this is the right place to report an SDK bug or
ask a question, and they survive the sync. For anything else, reach us at
<https://shield360.ai>.

The `docs/` directory holds this SDK's documentation, shipped here so the
links in the README resolve wherever the package is read.
